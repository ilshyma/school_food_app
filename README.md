# 🍲 Харчування Онлайн

Система замовлення шкільного харчування на Google Sheets + Apps Script: вебформа для батьків,
адмінпанель, облік оплат і балансів, звіти для кейтерингу. Без сервера й без оплати хостингу.

## Швидкий старт

1. Нова Google-таблиця → **Extensions → Apps Script** → вставити `Code.gs`, створити HTML-файли `Index` і `Admin`.
2. Оновити таблицю → меню **🍲 Харчування → 1. Створити/оновити службові листи**.
3. Заповнити «Список» (або [імпортувати](docs/import.md)), вказати понеділок тижня в «Налаштуваннях».
4. **Deploy → New deployment → Web app**, *Execute as: Me*, *Who has access: Anyone* → URL у «Налаштування».

Покроково з кожним полем — [Розгортання з нуля](docs/setup/install.md).
