# Лист «Ціни»

| Прийом | Ціна, грн | Діє з (дата) |
|---|---|---|
| Сніданок | 100 | |
| Обід | 230 | |
| Підвечірок | 100 | |

- **Прийом** — зі списку: Сніданок / Обід / Підвечірок.
- **Ціна** — ціле число більше нуля. Однакова для варіантів №1 і №2.
- **Діє з** — дата, з якої ціна чинна. Порожньо = «від початку часів».

Це **базові ціни кейтерингу**: у їхньому шаблоні «Всього» рахується саме як сніданок **100**, обід **230**,
підвечірок **100** грн. Пункт меню **1. Створити/оновити службові листи** прописує їх сам:

- у новій таблиці — одразу;
- у таблиці, де досі стоять старі стартові заглушки **90 / 200 / 90** (три рядки без дат), — замінює їх
  і повідомляє «Ціни оновлено до цін кейтерингу»;
- якщо ціни вже змінювали вручну або є рядки з датами «Діє з» — **нічого не чіпає**.

> Уже збережені замовлення зберігають суму за старими цінами (сума тижня заморожена). Нові збереження
> рахуються за новими цінами.

Ціни мають збігатися з рахунком кейтерингу, інакше баланси батьків розійдуться з ним.

## Зміна ціни — додавайте рядок, не редагуйте

Щоб із листопада обід коштував 250 грн, **додайте** рядок, старий не чіпайте:

| Прийом | Ціна, грн | Діє з (дата) |
|---|---|---|
| Обід | 230 | |
| Обід | 250 | 01.11.2026 |

**Як обирається ціна:** для кожного тижня береться рядок цього прийому з найпізнішою датою
«Діє з», яка **не пізніше понеділка** тижня.

| Тиждень | Ціна обіду |
|---|---|
| 26.10–30.10 (понеділок 26.10) | 230 |
| 02.11–06.11 (понеділок 02.11) | 250 |

Тобто ціна змінюється лише з цілого тижня, ніколи посеред тижня. Якщо «Діє з» припадає на середу,
нова ціна почне діяти з **наступного** понеділка.

## Що відбувається з уже збереженими замовленнями

Нічого. Сума кожного тижня **заморожена** в колонці «Сума» листа «Замовлення» на момент
збереження. Зміна ціни заднім числом не змінює баланси.

Виняток: якщо батько **знову збереже** старий тиждень (наприклад, адміністратор тимчасово
відкрив зміни), сума перерахується за цінами того самого понеділка, тобто за правильними.

## Помилки

| Ситуація | Результат |
|---|---|
| для прийому немає жодного рядка | прийом коштує **0 грн** — у формі видно «0 грн» |
| два рядки з однаковою датою | береться нижній |
| ціну вписали текстом («200 грн») | таблиця не прийме — лише число |
