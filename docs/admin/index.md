# Адміністратор

Роль адміністратора: раз на тиждень оновити меню й тиждень, щодня надрукувати порції,
вносити оплати, вести список дітей і передавати зміни кейтерингу.

Звичайний тиждень забирає приблизно **15 хвилин**: 2–3 хвилини на перемикання тижня
і по хвилині щоранку на друк.

## Два робочі місця

| Де | Для чого |
|---|---|
| **Google-таблиця** з меню «🍲 Харчування» | налаштування, меню, ціни, правила, службові дії |
| **Адмінпанель** — посилання `…/exec?admin=…` | щоденна робота: порції на день, оплати, список дітей. Працює й з телефону |

## Золоті правила

Ці правила захищають дані. Порушення більшості з них не ламає систему назавжди,
але створює плутанину, яку довго розбирати.

1. **Дітей не видаляти — архівувати.** Статус `архів` ховає дитину, але зберігає історію й баланс.
2. **Не редагувати руками службові листи**: «МенюДані», «Зведення», «Баланс», «Токени» —
   скрипт їх перезаписує, правки зникнуть.
3. **Перейменовувати дитину — тільки через картку в адмінпанелі.** Панель сама перенесе замовлення,
   оплати й журнал на нове ім'я. У листі «Список» напряму — лише разом із ручною заміною по всіх листах
   (див. [Типові задачі](tasks.md)).
4. **«Примітку» бачать батьки** цієї дитини у формі. Не пишіть туди того, що не можна показати родині.
5. **Адмін-посилання — як пароль.** Не пересилати в чати, не давати батькам.
6. **Змінили код — випустіть нову версію деплою.** Інакше батьки працюють зі старим (див. [Деплой](../setup/deploy.md)).
7. **Меню і тиждень перемикати разом**, в один підхід (див. [Щотижневий цикл](weekly.md)).
