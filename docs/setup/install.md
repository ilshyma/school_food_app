# Розгортання з нуля

Усе робиться під тим акаунтом Google, **який буде власником** системи: від його імені працює форма,
з нього йдуть листи, на ньому лежить таблиця. Для школи краще завести окремий акаунт
(наприклад, `harchuvannia.school@gmail.com`), а не особистий, — так систему простіше передати.

## 1. Таблиця й код

1. Створіть нову Google-таблицю: [sheets.new](https://sheets.new). Назвіть, наприклад, «Харчування».
2. **Розширення → Apps Script** (англ. *Extensions → Apps Script*). Відкриється редактор коду з файлом `Code.gs`.

> Назви кнопок нижче подано так, як вони виглядають в англійському інтерфейсі Google, з українським
> відповідником у дужках — переклад інтерфейсу Google іноді змінюється, а англійські назви стабільні.
3. Відкрийте [Code.gs у репозиторії](https://github.com/ilshyma/school_food_app/blob/main/Code.gs) →
   кнопка **Raw** (або «Copy raw file») → скопіюйте все.
4. У редакторі: виділіть усе в `Code.gs` (`Ctrl+A`) → вставте (`Ctrl+V`).
5. Ліворуч **＋ → HTML** → назва **`Index`** (саме так, з великої літери, без `.html`) →
   вставте вміст [Index.html](https://github.com/ilshyma/school_food_app/blob/main/Index.html).
6. Ще раз **＋ → HTML** → назва **`Admin`** → вставте вміст [Admin.html](https://github.com/ilshyma/school_food_app/blob/main/Admin.html).
7. **Зберегти** (іконка дискети або `Ctrl+S`).

Має бути три файли: `Code.gs`, `Index.html`, `Admin.html`. Якщо файл названо інакше (`index`, `Index.html.html`),
форма не відкриється з помилкою «No HTML file named Index was found».

## 2. Перший запуск і дозволи

1. Поверніться на вкладку таблиці й **оновіть сторінку** (F5). Через кілька секунд у меню
   з'явиться **🍲 Харчування**.
2. **🍲 Харчування → 1. Створити/оновити службові листи**.
3. Google попросить дозвіл:
   - **Review permissions** (Переглянути дозволи) → оберіть акаунт;
   - «Google hasn't verified this app» → **Advanced** (Додатково) → **Go to … (unsafe)** (Перейти … (небезпечно)).
     Це ваш власний скрипт; «неперевірений» означає лише, що він не проходив публічну модерацію Google;
   - **Allow** (Дозволити).
4. Запустіть пункт 1 **ще раз** — перший запуск часто переривається на дозволах.

З'явиться 14 листів: Налаштування, Список, Ціни, Правила змін, Меню, МенюДані, Замовлення,
Оплати, Токени, Зведення, Баланс, Журнал змін, Кейтеринг: журнал, Імпорт.

## 3. Наповнення

1. **Діти** — у лист «Список» ([формат](../config/roster.md)) або, якщо є стара таблиця, через [Імпорт даних](../import.md).
2. **Ціни** — перевірте лист «Ціни» ([формат](../config/prices.md)). Стартові — ціни кейтерингу: 100 / 230 / 100.
3. **Правила змін** — стартові відповідають правилам кейтерингу ([детально](../config/rules.md)).
4. **Меню** — вставте в лист «Меню» і запустіть пункт 2 ([формат](../config/menu.md)).
5. **Тиждень** — «Налаштування» → «Понеділок тижня (дата)».

## 4. Публікація

Детально з поясненням кожного поля — [Деплой і оновлення](deploy.md). Коротко:

1. Редактор Apps Script → **Deploy → New deployment** → ⚙ → **Web app**.
2. **Execute as: Me**. **Who has access: Anyone**.
3. **Deploy** → скопіюйте **Web app URL** (закінчується на `/exec`).
4. Вставте його в «Налаштування» → **URL веб-додатку**.

## 5. Доступи й сповіщення

1. Меню → **Показати посилання на адмін-панель** → збережіть у закладки.
2. Меню → **3. Згенерувати персональні посилання** — лист «Токени» з посиланнями для родин.
3. Меню → **Увімкнути нагадування та email-сповіщення** (якщо потрібні листи).

## 6. Перевірка перед запуском

- ☐ форма в **анонімному вікні** відкривається без входу в Google;
- ☐ вхід з тестовим номером показує потрібну дитину;
- ☐ збереження тестового замовлення з'являється в «Замовленнях» і «Зведенні»;
- ☐ адмінпанель показує тестове замовлення в «Порціях на день»;
- ☐ тестова оплата в панелі змінює баланс і (якщо є email) приходить лист;
- ☐ **видаліть** тестові рядки із «Замовлень» і «Оплат» → меню → **Оновити «Зведення» і «Баланс»**.

## Демо-дані

У меню є два пункти з позначкою **ДЕМО** — для показу системи без реальних даних:

- **ДЕМО: імпортувати дітей зі шкільної таблиці** — додає вбудований список імен у «Список» (без дублів);
- **ДЕМО: згенерувати тестові замовлення** — випадкові замовлення на активний тиждень тим, у кого їх ще немає
  (~15 % «не відповіли»).

**У робочій системі їх не запускайте.** Якщо запустили випадково: видаліть згенеровані рядки
в «Замовленнях» (фільтр за тижнем) і архівуйте зайвих дітей.
